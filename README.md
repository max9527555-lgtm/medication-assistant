# 用药助手

使用方式：打开此仓库的 GitHub Pages 网址 → 输入访问密码 → 等待“离线资源已就绪” → 添加到主屏幕。完成缓存及首次解锁后可离线使用，不需要电脑服务器或本地证书。

- iPhone：在 Safari 打开网站，通过分享菜单添加到主屏幕，再从主屏幕图标打开并解锁。
- Android：在 Chrome 打开网站，通过菜单安装或添加到主屏幕。
- Windows：在 Edge 或 Chrome 打开相同网址，可使用浏览器提供的安装入口。

访问密码由资料所有者提供，本仓库不包含明文密码。药品和规则初始包为加密文件，浏览器中的本地更新也以密文保存在 IndexedDB。每个设备及入口的本地更新相互独立，不自动同步；浏览器清理可能删除更新，请保留维护源文件。

支持单框药名、拼音、规格和症状查询，类别/剂型筛选，日夜模式和最多五药核对。症状只匹配主要功效和适应病症。规则提醒保留来源及条件，未命中不是合用安全结论。规则 Excel 由资料所有者在本地维护并导入。

发布来源为仓库 main 分支根目录，使用 GitHub Pages 自带 HTTPS。`.nojekyll` 表示直接提供静态文件，无需构建链。应用资源和数据库按站点路径隔离，兼容 `用户名.github.io/仓库名/` 子目录。

本仓库只发布网页、开源运行依赖与许可证、加密初始资料包。不要上传原始 Excel/Word、明文规则表、密码、证书、私钥、服务器脚本或工作目录。
